# Park Player · 파크 플레이어

[게임 실행하기](https://parkplayer.playpark.app/) · [기존 공유 링크](https://playpark-admin.github.io/playpark-golf-demo/)

게임 화면, 관리자 화면, 인증과 통계는 별도 Park Player Firebase 프로젝트에서 실행됩니다. 이 공개 저장소는 예전 GitHub Pages 공유 링크를 Firebase 게임으로 연결하는 안내 페이지만 보관합니다. 게임 소스와 Android/iOS 프로젝트는 비공개 개발 저장소에서 관리합니다.

개발 저장소의 main 변경이 테스트를 통과하면 이 안내 페이지의 소스 버전이 갱신됩니다. 실제 게임 배포는 Firebase에서 별도로 확인해야 합니다. 주소가 바뀌면 브라우저의 기기별 플레이 기록은 자동으로 이동하지 않습니다.
